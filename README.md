# Agent能力看板

这是一个用于展示 DataAgent 能力建设、知识库、Session 分析和运行状态的响应式前端看板。项目根据线上 NoCode 原型重构为可独立维护的源码，不依赖原 NoCode 平台运行。

## 功能

- 能力地图与七维雷达图
- Skill 分类、完成度与展开交互
- 知识库分类和即时搜索
- Session 类型、身份筛选及指标联动
- 运行巡检与质量文件状态
- 每周总结与综合评分
- 桌面端、平板和手机端响应式布局

## 本地运行

无需安装依赖，直接使用任意静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 数据接入

当前仓库内的数据为原型展示数据，统一存放在 `app.js` 顶部。生产环境可将这些数组替换为 API 请求，并在接口层处理鉴权、加载和异常状态。

## 部署

项目是纯静态站点，可直接部署到 GitHub Pages、Cloudflare Pages、Vercel 或任意静态文件服务器。
